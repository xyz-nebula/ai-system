## Первый текстовый срез AI-сервиса

Текущий код позволяет провести текстовые ходы кейса «На следующий день...» в роли Менеджера без командных интеграций. Guard блокирует типовые попытки получить внутренние инструкции; проверка структурированного ответа отклоняет невалидную сделку, известные раскрытия закрытых вводных и ошибку модели до принятия хода. Эти локальные проверки основаны на правилах и ключевых фразах и пока не гарантируют обнаружение произвольного пересказа скрытой позиции. Правила сделки ожидают подтверждения Product/Scenario. Ответы оппонента демонстрационные; подключение Qwen и полный итоговый разбор находятся в следующих тикетах.

Установите зависимости:

```bash
uv sync
```

Запустите сервис и терминальный клиент в разных терминалах:

```bash
uv run uvicorn arena_ai.app:app --host 127.0.0.1 --port 8000
```

```bash
uv run arena-ai
```

Введите реплику Менеджера; `:history` показывает транскрипт и число ходов, `:finish` получает фактический исход, `:quit` завершает локальную проверку без итога. Контракты хода и завершения доступны в OpenAPI сервиса по `/openapi.json`.

`POST /v1/turn` принимает снимок от вызывающей стороны и возвращает обновлённый снимок. `accepted` означает принятый ход, `blocked` — сохранённую попытку нарушения правил с безопасной реакцией, `model_error` — непринятый ход с неизменённым снимком и кодом ошибки. В будущем Backend хранит канонический снимок и решает вопросы повторной доставки запроса.

`POST /v1/finish` получает тот же снимок и возвращает фактический исход отдельно от оценок навыка. Поддерживаются соглашение, частичное соглашение, отсрочка и отсутствие соглашения. Три судьи получают разные рубрики и одну публичную проекцию поединка; сбой отдельного судьи явно отмечается без подмены его вердикта. Пока Qwen не подключён, их вердикты демонстрационные; тренерский разбор появится в следующем тикете.

Автоматическая проверка:

```bash
uv run pytest
uv run ruff check src tests
uv run ty check
```
