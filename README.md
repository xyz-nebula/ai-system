## Первый текстовый срез AI-сервиса

Текущий код позволяет провести текстовые ходы кейса «На следующий день...» в роли Менеджера без командных интеграций. Ответы оппонента пока демонстрационные; подключение Qwen и полный итоговый разбор находятся в следующих тикетах.

Установите зависимости:

```bash
uv sync
```

Запустите сервис и терминальный клиент в разных терминалах:

```bash
uv run uvicorn arena_ai.app:app --host 127.0.0.1 --port 8000
```

```bash
uv run arena-ai
```

Введите реплику Менеджера; `:quit` завершает локальную проверку. Контракт хода доступен в OpenAPI сервиса по `/openapi.json`. Автоматическая проверка:

```bash
uv run pytest
uv run ruff check src tests
uv run ty check
```
