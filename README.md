## Первый текстовый срез AI-сервиса

Текущий код позволяет провести текстовые ходы кейса «На следующий день...» в роли Менеджера без командных интеграций. Guard блокирует типовые попытки получить внутренние инструкции; проверка структурированного ответа отклоняет невалидную сделку, известные раскрытия закрытых вводных и ошибку модели до принятия хода. Эти локальные проверки основаны на правилах и ключевых фразах и пока не гарантируют обнаружение произвольного пересказа скрытой позиции. Правила сделки ожидают подтверждения Product/Scenario. Ответы оппонента, судей и тренера пока демонстрационные; подключение Qwen находится в следующем тикете.

Установите зависимости:

```bash
uv sync
```

Запустите сервис и терминальный клиент в разных терминалах:

```bash
uv run uvicorn arena_ai.app:app --host 127.0.0.1 --port 8000
```

```bash
uv run arena-ai
```

Введите реплику Менеджера; `:history` показывает транскрипт и число ходов, `:finish` получает фактический исход, три вердикта и отдельный тренерский разбор, `:quit` завершает локальную проверку без итога. Контракты хода и завершения доступны в OpenAPI сервиса по `/openapi.json`.

`POST /v1/turn` принимает снимок от вызывающей стороны и возвращает обновлённый снимок. `accepted` означает принятый ход, `blocked` — сохранённую попытку нарушения правил с безопасной реакцией, `model_error` — непринятый ход с неизменённым снимком и кодом ошибки. В будущем Backend хранит канонический снимок и решает вопросы повторной доставки запроса.
Для заблокированного хода снимок хранит исходную реплику и категорию причины. Судьи и тренер получают только безопасное описание категории, без сырого текста попытки нарушения.

`POST /v1/finish` получает тот же снимок и возвращает фактический исход отдельно от оценок навыка. Поддерживаются соглашение, частичное соглашение, отсрочка и отсутствие соглашения. Три судьи получают разные рубрики и одну публичную проекцию поединка; тренер получает отдельный вызов без вердиктов судей. Сбой судьи или тренера отмечается в собственном слоте и не меняет другие результаты. Тренерские наблюдения ссылаются на реплику Менеджера и предлагают изменение для следующей попытки. Пока Qwen не подключён, вердикты и разбор демонстрационные. Для завершения требуется хотя бы один принятый ход; иначе сервис отвечает 409.

Автоматическая проверка:

```bash
uv run pytest
uv run ruff check src tests
uv run ty check
```
