## Agent skills

### Issue tracker

Track issues and specs as Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles as `Status:` values in local issue files. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single context at the repo root, with `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
