# 01: Первый текстовый ход поединка

**What to build:** AI Engineer запускает отдельный сервис и терминальный клиент, начинает кейс «На следующий день...» в роли Менеджера, отправляет текстовую реплику и получает ответ Генерального директора. Клиент хранит локальный снимок поединка, а сервис возвращает структурированный результат одного хода без постоянного хранения.

**Blocked by:** None (can start immediately).

Status: ready-for-agent

- [ ] Из чистого запуска сервиса и клиента можно провести как минимум один текстовый ход первого кейса через публичный HTTP API.
- [ ] Терминальный клиент показывает только общие и ролевые вводные Менеджера, а модельный вызов оппонента получает только разрешённую ему проекцию кейса и истории.
- [ ] Ответ API содержит идентификаторы поединка и хода, принятую реплику, новое состояние и событие транскрипта; следующий ход можно отправить с возвращённым снимком.
- [ ] Сквозной тест через HTTP API с управляемой моделью проверяет ход и отсутствие вводных Менеджера во входе оппонента.
