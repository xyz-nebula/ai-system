# 04: Три независимых судейских вердикта

**What to build:** После завершения поединка пользователь получает выбор и объяснение от каждой из трёх судейских коллегий: «Нанимающиеся на работу», «Отправляющие на переговоры» и «Доверяющие собственность».

**Blocked by:** 03: Фактический исход поединка.

Status: ready-for-agent

- [x] Итоговая операция возвращает по одному структурированному вердикту каждой коллегии с обязательным выбором стороны и объяснением «выбор → наблюдение → эффект → сравнение».
- [x] Каждый судья вызывается независимо со своей рубрикой, одинаковым разрешённым снимком поединка и без вердиктов других судей.
- [x] Судьи ссылаются на наблюдаемые эпизоды транскрипта; сырые приватные вводные кейса не попадают в их входы или публичный результат.
- [x] Если один вызов не удался, результат явно отмечает отсутствие именно этого вердикта и не подставляет голос другой коллегии.
- [x] Сквозной тест через API проверяет три отдельные модельные операции и формат итогового результата.
