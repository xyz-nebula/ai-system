# 06: Живой текстовый ход через Qwen

**What to build:** AI Engineer подключает доступный текстовый Qwen endpoint через конфигурацию сервиса и проводит тот же кейс в терминальном клиенте с ответами реальной модели. Управляемая модель остаётся средством автоматических тестов.

**Blocked by:** 02: Защищённый ход.

Status: ready-for-agent

- [ ] После получения несекретных параметров Model/Infra сервис использует указанный endpoint и модель без изменения предметной логики хода.
- [ ] Терминальный клиент проходит несколько текстовых ходов с живым Qwen, сохраняя Guard и проверку ответа до принятия реплики.
- [x] Таймаут, недоступность endpoint и неверный структурированный вывод дают явную безопасную ошибку без раскрытия сырого ответа или секретов.
- [ ] Семантическая проверка на Qwen дополняет локальные правила Guard и валидатора: перефразированные закрытые позиции и противоречивое согласие не становятся принятым ходом; при неопределённом результате проверка завершается безопасной ошибкой.
- [x] Автоматические проверки адаптера используют управляемые ответы; секреты передаются только через локальную конфигурацию и не попадают в логи или документацию.
