# 05: Отдельный тренерский разбор

**What to build:** После завершения поединка пользователь получает разбор своих действий с конкретными сильными моментами, ошибками, последствиями и советом для следующей попытки, независимо от голосования судей.

**Blocked by:** 03: Фактический исход поединка.

Status: ready-for-agent

- [x] Итоговая операция возвращает тренерский разбор отдельно от фактического исхода и судейских вердиктов.
- [x] Разбор опирается на конкретные эпизоды транскрипта и предлагает проверяемое изменение поведения для следующей попытки.
- [x] Отсутствующая карточка подготовки не считается ошибкой; сравнение плана с действиями опускается в первом срезе.
- [x] Отказ тренерского вызова отображается как отсутствующий разбор и не меняет фактический исход или вердикты коллегий.
- [x] Сквозной тест через API проверяет отдельный вызов тренера и его разрешённую проекцию данных.

## Comments

- 2026-09-20: `POST /v1/finish` вызывает тренера отдельно после судей, не передавая ему приватные вводные и вердикты. Структура разбора хранит цитату/`turn_id`, действие, изменение ситуации, последствие и совет. Демонстрационный тренер обозначен как заглушка качества до Qwen; правила содержательного разбора стоит подтвердить с Product/Scenario.
