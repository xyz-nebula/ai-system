# 05: Отдельный тренерский разбор

**What to build:** После завершения поединка пользователь получает разбор своих действий с конкретными сильными моментами, ошибками, последствиями и советом для следующей попытки, независимо от голосования судей.

**Blocked by:** 03: Фактический исход поединка.

Status: ready-for-agent

- [ ] Итоговая операция возвращает тренерский разбор отдельно от фактического исхода и судейских вердиктов.
- [ ] Разбор опирается на конкретные эпизоды транскрипта и предлагает проверяемое изменение поведения для следующей попытки.
- [ ] Отсутствующая карточка подготовки не считается ошибкой; сравнение плана с действиями опускается в первом срезе.
- [ ] Отказ тренерского вызова отображается как отсутствующий разбор и не меняет фактический исход или вердикты коллегий.
- [ ] Сквозной тест через API проверяет отдельный вызов тренера и его разрешённую проекцию данных.
