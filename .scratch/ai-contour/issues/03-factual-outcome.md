# 03: Фактический исход поединка

**What to build:** Пользователь завершает текстовый поединок из терминального клиента и видит отдельный фактический исход: достигнутую договорённость, её условия или причину отсутствия соглашения. Этот результат не выдаёт оценку навыка.

**Blocked by:** 01: Первый текстовый ход поединка.

Status: ready-for-agent

- [ ] Операция завершения принимает финальный снимок поединка и возвращает структурированный исход отдельно от судейских вердиктов и тренерского разбора.
- [ ] Исход различает как минимум соглашение, частичное соглашение, отсрочку решения и отсутствие соглашения; для договорённости отражает обсуждённые обязательства и условия.
- [ ] Терминальный клиент показывает исход после нескольких ходов первого кейса без интеграции с Backend.
- [ ] Сквозные сценарии через API проверяют разные возможные исходы и не приравнивают соглашение к хорошей игре.
