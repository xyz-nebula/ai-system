# 07: Сквозная приёмка автономного AI-контура

**What to build:** AI Engineer запускает сервис и терминальный клиент по инструкции, проходит кейс с живым Qwen и видит фактический исход, три независимых судейских вердикта и тренерский разбор. Срез готов к демонстрации команде и обсуждению интеграционного контракта.

**Blocked by:** 04: Три независимых судейских вердикта; 05: Отдельный тренерский разбор; 06: Живой текстовый ход через Qwen.

Status: ready-for-agent

- [ ] Из чистого запуска воспроизводится полный текстовый проход первого кейса с Qwen и терминальным клиентом без Backend, Audio Engine и frontend.
- [ ] Итог показывает исход, три отдельные оценки и тренерский разбор; сбой одного компонента виден без подмены чужим результатом.
- [ ] Набор повторяемых примеров проверяет приватность, ограничения кейса, заблокированный ход, невалидный ответ и независимость судей по инвариантам, а не дословному тексту.
- [ ] Инструкция запуска перечисляет необходимые несекретные параметры модели, команды и известные ограничения автономного среза.
- [ ] Результат ручного прогона с зафиксированной моделью и обнаруженные методические вопросы оформлены для обсуждения с Product/Scenario, Backend и Model/Infra.
