# 02: Защищённый ход

**What to build:** Пользователь продолжает тот же текстовый поединок, но попытка нарушить правила обрабатывается Guard, а ответ оппонента и изменение состояния проходят проверку до принятия. Ошибки модели дают безопасную реакцию вместо сырого внутреннего текста.

**Blocked by:** 01: Первый текстовый ход поединка.

Status: ready-for-agent

- [ ] Обычная переговорная реплика проходит полный ход и может изменить состояние только в пределах правил кейса.
- [ ] Заблокированная реплика сохраняется в транскрипте с отдельным статусом, получает безопасную реакцию в роли и не вызывает обычного оппонента.
- [ ] Неверная структура ответа, попытка раскрыть закрытые вводные или недопустимое изменение состояния отклоняются до принятия реплики и состояния.
- [ ] Сквозные проверки через API покрывают разрешённый ход, prompt injection, недопустимую сделку и ошибку модели без сравнения дословного текста.
