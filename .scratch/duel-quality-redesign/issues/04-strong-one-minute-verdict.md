# 04: Сильный минутный вердикт судьи

**What to build:** После поединка каждая коллегия выдаёт короткий проверяемый комментарий, который объясняет свой голос одним критерием, одним решающим эпизодом, его эффектом и сравнением участников.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Публичный судейский вердикт содержит выбор, один решающий критерий своей коллегии, точный `turn_id` и цитату, эффект и сравнение участников.
- [ ] Совокупный комментарий укладывается примерно в 120 слов и не пересказывает весь поединок.
- [ ] Судья не оценивает личность, уверенность или красноречие без наблюдаемого влияния на ситуацию.
- [ ] Судья не даёт тренерских советов и не подменяет отдельный Trainer.
- [ ] Публичный ответ не содержит названий методик, источников, страниц, ссылок, выдержек или упоминания RAG.
- [ ] Три коллегии применяют разные практические вопросы и могут содержательно оценить один эпизод по-разному.
- [ ] Невалидный, общий или не связанный с рубрикой результат получает ограниченный retry, а затем явный failed-слот без выдуманного fallback.
- [ ] Публичные тесты `/v1/finish`, CLI-вывод, OpenAPI и примеры подтверждают новый формат без доступа к приватным вводным.
