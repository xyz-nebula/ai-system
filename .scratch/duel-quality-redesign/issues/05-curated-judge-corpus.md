# 05: Курируемый судейский корпус

**What to build:** Методист может воспроизводимо загрузить в Qdrant проверенный корпус реальных судейских и переговорных методик, разделённый по коллегиям и пригодный для внутреннего поиска без примеси кейсов или приватных вводных.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] Внутри `ai-system` создан курируемый корпус с обязательным ядром гайда по судейству и только разрешёнными тематическими фрагментами методик.
- [x] Корпус не содержит кейсов, скрытых вводных, готовых примеров пользовательской аналитики или технических документов проекта.
- [x] Каждый фрагмент сохраняет точный исходный текст, источник, раздел или страницы, стабильный `chunk_id`, версию/хэш и применимые коллегии.
- [x] Сборка корпуса детерминирована и проверяет, что выдержка действительно присутствует в разрешённом исходном документе.
- [x] Ingestion использует Qwen3 Embeddings и идемпотентно создаёт или обновляет одну Qdrant-коллекцию с фильтрами по назначению и коллегии.
- [x] Повторная индексация не создаёт дубликаты и удаляет устаревшие фрагменты управляемой версии корпуса.
- [x] Retrieval-тесты для всех трёх коллегий возвращают ожидаемое ядро и не возвращают запрещённые типы данных.
- [x] Инструкции запуска, проверки и остановки retrieval-стека воспроизводимы и не затрагивают модельный порт `8080`.
