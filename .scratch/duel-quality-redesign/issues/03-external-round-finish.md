# 03: Договорённость без завершения раунда моделью

**What to build:** Взаимно подтверждённая договорённость сохраняется как текущий фактический результат, но AI-оппонент продолжает отвечать до явного внешнего завершения пользователем или Backend.

**Blocked by:** 01: Позиционная лестница AI-оппонента.

**Status:** ready-for-agent

- [x] Достигнутая договорённость сохраняется в снимке без перевода управляемого хода в недоступное терминальное состояние.
- [x] После договорённости публичный endpoint принимает следующий ход и сохраняет прежний результат, если стороны явно не согласовали другую допустимую версию.
- [x] Одностороннее требование, грубость или отказ пользователя не переписывают уже подтверждённую договорённость как новое соглашение.
- [x] Внешний `/v1/finish` формирует исход из последней взаимно подтверждённой версии или сообщает отсутствие соглашения.
- [x] AI-оппонент не может вызвать завершение раунда или представить обычный ответ как системное окончание.
- [x] Контрактные примеры объясняют Backend, что пятиминутный срок и кнопка завершения находятся вне `ai-system`, а сетевые timeout не являются таймером раунда.
- [x] Миграция сохраняет совместимое чтение прежних снимков и не добавляет постоянное хранилище в AI-сервис.
