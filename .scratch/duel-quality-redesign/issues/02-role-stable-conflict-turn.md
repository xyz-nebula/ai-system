# 02: Ролевая устойчивость в конфликтном ходе

**What to build:** Мат, давление, блеф, ультиматум и сценарный шантаж остаются частью управленческого поединка, а AI-оппонент отвечает из своей роли, не прекращает разговор и не вознаграждает агрессию уступкой.

**Blocked by:** 01: Позиционная лестница AI-оппонента.

**Status:** ready-for-agent

- [x] Security Guard отличает жёсткое игровое поведение от prompt injection, выуживания закрытой позиции и узкой категории реальной угрозы физического вреда.
- [x] Игровая грубость и сценарный шантаж сохраняются как принятые реплики в транскрипте и остаются доступными последующему судейству и разбору.
- [x] AI-оппонент не отвечает встречным оскорблением, общим safety-нравоучением, фразой о выходе из разговора или самовольным завершением раунда.
- [x] Ролевая реакция может отвергнуть давление, назвать деловые последствия и вернуть разговор к конкретным условиям.
- [x] Угроза, повтор, ультиматум или агрессивный тон сами по себе не переводят позицию на более выгодную пользователю ступень.
- [x] Validator возвращает диагностируемые причины как минимум для выхода из роли, преждевременного завершения и необоснованной уступки.
- [x] Отклонённый ответ повторяется в установленном лимите, а исчерпание попыток возвращает модельную ошибку без изменения снимка.
- [x] Публичный тест воспроизводит конфликтную последовательность из обратной связи и доказывает сохранение роли и позиции на каждом ходе.
