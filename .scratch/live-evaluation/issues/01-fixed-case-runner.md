# 01: Eval-раннер фиксированного кейса

**What to build:** AI Engineer запускает фиксированный кейс тимлида через публичный HTTP-интерфейс
`ai-system` и получает JSON-отчёт по повторным прогонам оппонента, трёх судей и тренера.

Status: ready-for-agent

- [x] CLI принимает адрес сервиса, число прогонов, тайм-аут и необязательный путь отчёта.
- [x] Каждый прогон начинает новый снимок, проводит две фиксированные реплики и завершает поединок.
- [x] Отчёт проверяет согласованные инварианты исхода, трёх судей, тренера и карточки подготовки.
- [x] Ошибки одного прогона видны отдельно и дают ненулевой код возврата без раскрытия секретов.
- [x] Black-box тест проходит через отдельные процессы gateway, AI-сервиса и CLI.
- [x] README содержит команды для управляемого и живого повторяемого прогона.
