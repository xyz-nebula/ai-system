# 02: Проверяемое сопоставление подготовки с поединком

Status: ready-for-agent
Blocked by: 01

**What to build:** Расширить тренерский разбор структурированным `plan_vs_reality`, которое использует только элементы переданной карточки и наблюдаемые реплики пользователя.

## Acceptance Criteria

- [x] Для непустой карточки успешный тренерский разбор содержит хотя бы один элемент со статусом `followed`, `adapted` или `not_observed`.
- [x] `followed` и `adapted` ссылаются на существующую принятую реплику пользователя и дословную цитату; `not_observed` не содержит доказательства.
- [x] Текст и вид сопоставляемого элемента присутствуют в исходной карточке; выдуманные элементы отклоняются как `invalid_trainer_output`.
- [x] При непустой карточке отсутствующее или невалидное сопоставление отклоняется только в `TrainerSlot`, не меняя исход и судей.
- [x] DemoTrainer и QwenTrainer соблюдают один контракт, а автоматические тесты не требуют живой модели.
