# 03: Автономный клиент и интеграционный комплект подготовки

Status: ready-for-agent
Blocked by: 02

**What to build:** Дать терминальному клиенту локальную загрузку карточки, показать сопоставление в итогах и обновить воспроизводимые контрактные материалы.

## Acceptance Criteria

- [x] Терминальный клиент опционально загружает карточку из локального JSON-файла, валидирует её до поединка и передаёт только в `/v1/finish`.
- [x] Клиент отдельно показывает соблюдённые, адаптированные и не проявившиеся элементы подготовки; без карточки вывод остаётся прежним.
- [x] README документирует формат локальной карточки и демонстрационный запуск без Backend и живого Qwen.
- [x] Зафиксированная OpenAPI-схема и пример запроса отражают необязательную карточку и структурированное сопоставление.
- [x] Black-box или CLI-проверка воспроизводит новый путь на управляемом gateway и не раскрывает карточку оппоненту или судьям.
