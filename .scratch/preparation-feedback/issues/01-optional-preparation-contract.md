# 01: Необязательная карточка в операции завершения

Status: ready-for-agent

**What to build:** Добавить частично заполняемую `PreparationCard` в публичный запрос завершения и передавать непустую карточку только тренеру, сохранив прежнее поведение без подготовки.

## Acceptance Criteria

- [x] `POST /v1/finish` принимает отсутствующую, пустую или частично заполненную карточку подготовки без изменения `SessionSnapshot`.
- [x] Непустая карточка представлена структурированными полями анализа, целей, вопросов, решений и аргументов и попадает в `TrainerContext`.
- [x] Оппонент и три судьи не получают карточку подготовки; операция хода и их публичные контракты не меняются.
- [x] При отсутствии или пустой карточке существующий JSON-ответ завершения остаётся совместимым и не содержит `plan_vs_reality`.
- [x] Автоматические проверки проходят через публичный HTTP API и покрывают приватную проекцию данных.
