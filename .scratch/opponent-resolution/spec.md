# Единственный структурированный исход Opponent

Status: ready-for-agent

## Problem Statement

`OpponentProposal` предлагает модели два независимых nullable-поля — `agreement` и `decision`,
а их взаимоисключение проверяет только Pydantic `model_validator` после генерации. Это ограничение
не выражено в JSON Schema достаточно явно для небольшой Qwen-модели. Живая wire-диагностика
зафиксировала две последовательные попытки с обоими заполненными полями; безопасный Validator
вынужден отклонять такие ответы.

## Solution

Заменить два поля одним nullable `resolution`, содержащим discriminated union полного соглашения,
частичного соглашения или переноса. Обычная реплика использует `resolution=null`. Внутри AI-контура
полное соглашение преобразуется в существующий `SessionState.agreement`, остальные варианты — в
`SessionState.decision`; публичные HTTP-схемы хода и завершения не меняются.

## Implementation Decisions

- Каждый вариант resolution имеет обязательный `kind`: `agreement`, `partial_agreement` или
  `deferred`; discriminator входит в JSON Schema модельного ответа.
- У модели физически один слот результата, поэтому полное и частичное решение нельзя вернуть
  одновременно.
- Локальные правила допустимых условий, приватности и явного согласия сохраняются.
- Prompt объясняет, когда использовать каждый `kind`, но структурная корректность обеспечивается
  прежде всего схемой.
- Bounded retry из предыдущего среза остаётся и повторяет полностью невалидный resolution.

## Testing Decisions

- Публичный `/v1/turn` остаётся основным seam: normal, agreement, partial и deferred проходят через
  один модельный output contract и дают прежний внешний снимок.
- Тест model gateway проверяет, что JSON Schema содержит один `resolution` с discriminator и не
  содержит соседних `agreement`/`decision`.
- Невалидный `kind`, отсутствующие обязательные поля и недопустимая сделка не продвигают снимок.
- После автоматических тестов выполнить три живых eval-прогона на зафиксированной модели.

## Out of Scope

- Изменение публичных `SessionState`, `TurnResponse` и `FinishResponse`.
- Ослабление предметных валидаторов или публикация сырого model output.
- Увеличение `ARENA_MODEL_MAX_ATTEMPTS` сверх текущего лимита.
