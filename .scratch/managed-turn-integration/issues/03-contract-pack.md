# 03: Воспроизводимый интеграционный комплект

**What to build:** Backend Engineer получает зафиксированный и автоматически проверяемый контракт управляемого хода с примерами основных результатов, а команды Backend и Audio Engine — точные границы своей интеграционной работы.

**Blocked by:** 01: Защищённые операции поединка; 02: Наблюдаемая готовность AI-сервиса.

**Status:** ready-for-agent

- [ ] В репозитории зафиксирована актуальная OpenAPI-схема AI-сервиса и её расхождение с работающим приложением обнаруживается автоматической проверкой.
- [ ] Интеграционные примеры покрывают `accepted`, `blocked`, `model_error`, конфликт завершённого поединка и авторизацию без раскрытия приватных вводных или секретов.
- [ ] Black-box сценарий запускает отдельные HTTP-процессы AI-сервиса и управляемого OpenAI-compatible gateway без импорта внутренних фабрик приложения.
- [ ] Black-box сценарий проверяет готовность, принятый ход, заблокированную попытку, ошибку модели и неизменность снимка при ошибке.
- [ ] Подготовлены готовые к отправке сообщения командам Backend и Audio Engine с ожидаемыми контрактами, ответственностью за состояние и запретом обхода Guard/Validator.
- [ ] Инструкция запуска позволяет воспроизвести интеграционную проверку без живого Qwen.
