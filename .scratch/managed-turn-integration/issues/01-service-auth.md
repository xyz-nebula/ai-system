# 01: Защищённые операции поединка

**What to build:** Backend вызывает управляемый ход и завершение поединка с межсервисным Bearer token в интеграционном окружении, а локальная разработка без настроенного токена продолжает работать без дополнительных действий.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] Если service token настроен, `/v1/turn` и `/v1/finish` принимают только точный Bearer token и одинаково отклоняют отсутствующее или неверное значение с HTTP 401.
- [x] Если service token не настроен, существующие локальные и тестовые вызовы операций поединка продолжают работать без заголовка авторизации.
- [ ] `/v1/info`, OpenAPI и health-check не требуют service token. `/v1/info` и OpenAPI проверены; health-check появится в тикете 02.
- [x] Секрет не попадает в ответ, логи или публичную конфигурацию сервиса.
- [x] Автоматические проверки покрывают включённую и отключённую авторизацию через публичный HTTP API.

## Comments

- Реализация завершена для существующих операций и публичных metadata endpoints. Критерий health-check остаётся открытым до тикета 02, где будут добавлены сами endpoints.
