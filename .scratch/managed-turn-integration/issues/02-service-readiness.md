# 02: Наблюдаемая готовность AI-сервиса

**What to build:** Оператор отличает работающий процесс AI-сервиса от готового модельного контура и получает безопасный ответ, когда gateway недоступен или не предоставляет настроенную модель.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Liveness сообщает об исправном HTTP-процессе без обращения к внешней модели.
- [ ] Readiness успешна в demo-режиме без внешних зависимостей.
- [ ] В Qwen-режиме readiness с ограниченным тайм-аутом проверяет OpenAI-compatible models endpoint и наличие настроенного идентификатора модели.
- [ ] Недоступный gateway, невалидный ответ или отсутствие модели возвращают HTTP 503 с безопасной категорией без сырого ответа провайдера.
- [ ] Информационный и health API не требуют service token.
- [ ] Автоматические проверки покрывают доступную модель, отсутствующую модель и сетевой отказ через публичный HTTP API.
