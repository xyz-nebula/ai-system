# Арена переговоров

«Арена переговоров» — тренажёр для практики переговоров с AI-оппонентом по подготовленным кейсам и разбора принятых решений.

## Язык проекта

**Кейс**:
Подготовленная переговорная ситуация с предысторией, игровыми ролями, интересами участников и возможными исходами. Один кейс может допускать несколько ролевых сочетаний.

**Игровая роль**:
Позиция участника внутри кейса со своими интересами, целями и доступной ему информацией.
_Avoid_: роль без уточнения, когда её можно спутать с социальной ролью.

**Социальная роль**:
Ожидаемый в отношениях участников способ поведения с характерными обязанностями, нормами и влиянием. Во время поединка участники могут пытаться изменить распределение социальных ролей.

**Ролевое сочетание**:
Предусмотренная кейсом пара игровых ролей, одну из которых выбирает пользователь, а другую исполняет AI-оппонент.

**Поединок**:
Один разговор пользователя и AI-оппонента в выбранных игровых ролях внутри кейса.

**Карточка подготовки**:
Запись анализа ситуации, стратегии и тактики пользователя перед поединком. Пользователь может начать поединок с незаполненной или частично заполненной карточкой.

**Сценарий переговоров**:
Намеченный пользователем путь от исходной ситуации к своей цели: вопросы, возможные решения и аргументы с учётом ответов оппонента. Это направление для разговора, которое можно менять по ходу поединка.
_Avoid_: сценарий без уточнения, когда его можно спутать с кейсом.

**Стратегическая цель ситуации**:
Желаемый результат для всей ситуации, учитывающий интересы её участников и направленный на разрешение корневого конфликта.

**Цель на переговоры**:
Конкретный, проверяемый результат, которого участник хочет достичь в данном разговоре.

**Исход переговоров**:
То, чем фактически завершился поединок, включая достигнутые договорённости, если они были. Исход сам по себе не определяет качество действий пользователя.

**Судейская коллегия**:
Одна из трёх перспектив оценки поединка: «Нанимающиеся на работу», «Отправляющие на переговоры» или «Доверяющие собственность». Каждая отвечает на свой практический вопрос о том, кому из участников доверить соответствующую функцию.

**Судейский вердикт**:
Независимый выбор одной из сторон по критериям конкретной коллегии, объяснённый наблюдаемым эпизодом, его эффектом и сравнением участников.

**Тренерский разбор**:
Обратная связь о действиях пользователя, их последствиях и возможных шагах для следующей попытки.

**Повторная попытка**:
Новый поединок с тем же ролевым сочетанием и теми же скрытыми вводными AI-оппонента, позволяющий попробовать другую стратегию.

**Администратор**:
Тренер или методист, который подготавливает кейсы и настраивает условия тренировки.
