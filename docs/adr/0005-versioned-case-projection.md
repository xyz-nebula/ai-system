# Версионируемая AI-проекция кейса вместо универсализации v1 на месте

Статус: предложен; требует согласования команд Backend, Frontend и AI.

Текущий v1 фиксирует условия одного кейса через KPI, недели контроля и повышение
зарплаты. Предлагаем сохранить v1 для существующих сессий, а универсальные предметы
торга, обязательства ролей и полную необязательную подготовку ввести отдельным v2.
Backend хранит полный версионированный бизнес-кейс и передаёт AI только разрешённую
проекцию для выбранных ролей. Цена — поддержка двух контрактов на переходный период;
выгода — не ломать сохранённые снимки и уже начатую интеграцию. Срок вывода v1,
маршруты внешнего приложения и переходное окно согласуются отдельно.

Целевая спецификация: [2.0.0-rc.1](../api/v2/README.md).
Это не утверждение, что v2 уже реализован или доступен на сервере.
