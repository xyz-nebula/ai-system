# Backend управляет порядком и повторной доставкой ходов

Статус: принят в `ai-system`; требуется согласование с командой Backend.

Backend назначает `turn_id`, допускает только один активный управляемый ход на поединок и решает вопросы повторной доставки. `ai-system` остаётся stateless и не дедуплицирует запросы: повтор после неоднозначного тайм-аута может вызвать модель снова и вернуть другой ответ. Это сохраняет простой AI-контур без отдельного хранилища, но требует от Backend не выполнять слепой автоматический retry после отправки запроса.
