# Отдельный AI-сервис

Статус: принят в `ai-system`; интеграционный контракт требует согласования с Backend.

AI-контур реализуем как отдельный сервис в `ai-system`; backend вызывает его по согласованному контракту и остаётся источником истины для состояния поединка и транскрипта. Такая граница позволяет развивать и запускать модельную логику независимо от backend и его хранилища. Цена решения — сетевой вызов и необходимость согласовывать изменения контракта между командами.
