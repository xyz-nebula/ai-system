# AI-сервис хранит только обезличенные замеры оценки

Статус: принят в `ai-system`.

Каждый вызов `/v2/evaluate` добавляет в файл на томе одну запись: готовность, длительность, токены и привязка цитат по этапам, выбор судей. Текста реплик, кейса, подготовки и ответов модели в записи нет, идентификатора чата тоже. Это не противоречит ADR 0002 и 0004: поединки по-прежнему хранит только Backend, сервис не читает записанное при обработке запросов, а повтор запроса ничего не дедуплицирует. Файл, а не логи контейнера, выбран потому, что логи пропадают при пересоздании контейнера. Склейку с голосовыми замерами audio-engine по `chat_uuid` отклонили: для неё пришлось бы менять контракт с Backend, а для средних по разговору склейка не нужна.
