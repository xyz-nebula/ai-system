# Контракт поединка

Статус: предлагаем команде Backend.

Для интеграции AI-сервиса описываем отдельный контракт поединка и хода: кейс, игровые роли, разрешённые проекции данных, состояние, транскрипт, фактический исход, три судейских вердикта и тренерский разбор. Существующий `/chat` хранит общие сообщения и может быть использован Backend повторно, но его текущая форма не выражает эти правила. Отдельная предметная граница требует дополнительных схем и согласования с Backend, зато не заставляет кодировать смысл поединка в текстовых сообщениях и одном статусе `victory/defeat`.
