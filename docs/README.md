## Контракт и история — разные вещи

`api/v2/*.schema.json`, OpenAPI и `examples/` — контрактные артефакты,
используемые проверками. Не удалять их как лишние JSON.
`api/openapi.json` и старые примеры нужны сохранённому v1-коду и его тестам;
новая интеграция использует v2.

Исторические исследования и этапы согласования:

- `api/drafts/` — прежнее предложение контракта, не инструкция новой интеграции;
- `integration/*audit*.md`, `backend-integration-review.md` — аудиты указанных
  снимков репозиториев, не утверждение об их сегодняшнем состоянии;
- `api/v2/hiring-diagnosis-2026-09-27.md`, `live-validation.md` — результаты
  конкретных экспериментов, не гарантия качества на всех кейсах;
- [серверный стенд](integration/server-deployment.md) и
  [сохранённый экземпляр](integration/staging-v2-checklist.md) — история запуска
  и откат, не рекомендуемый путь нового деплоя.

Эти документы сохранены, чтобы не потерять основания решений и ссылки.
Доменный словарь — [CONTEXT.md](../CONTEXT.md), архитектурные решения — `adr/`.

## Что не публикуется

`.scratch/`, кэши, виртуальные окружения, реальные `.env`, локальная копия
`knowledge-base/` и рабочие сообщения исключены через `.gitignore`.
Docker build context отдельно ограничен `.dockerignore`.
Рабочие записи сохраняются локально: уборка Git не требует их удаления.
